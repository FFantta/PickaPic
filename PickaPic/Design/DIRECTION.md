# Local edition design direction

Reference supplied by the founder: a collage of expressive mobile interfaces with bold typography, acid yellow, lavender, sage, pill actions and a black floating navigation bar. Use those visual principles, while preserving a quiet personal journal experience.

Additional reference inspected: [TravelDiary by Chechetkin Artem](https://dribbble.com/shots/25870014-TravelDiary-UI-UX-Design-for-Travel-Photo-Journal-Mobile-App), for photography hierarchy and photo journal navigation. Referenced for structure only. No reference images, logos or layouts are redistributed.

## Tokens

| Token | RGB | Usage |
| --- | --- | --- |
| Paper | 0.97, 0.96, 0.94 | Main canvas |
| Ink | 0.09, 0.10, 0.09 | Typography, floating dock |
| Lime | 0.86, 0.96, 0.29 | Primary action, selected tab |
| Lilac | 0.80, 0.75, 0.93 | Book cover |
| Sage | 0.78, 0.83, 0.70 | Empty photo area, chapter pages |

Large rounded titles, small monospaced editorial labels, generous 24-point gutters. Native sheets, photo permissions and export dialogs remain recognizable system surfaces. Avoid gradient dashboards, unrelated metrics, excessive frosted glass and decorative card grids.

Typography is system-provided; there is no font download. SF Symbols supply functional icons. The eight-petal flower and book are original SwiftUI vector artwork. Empty states contain no pretend journal data.
